# Workshop scenery — CC0 1.0

These are decorative environment assets, not research evidence or product anatomy.
Downloaded and inspected 2026-11-02. All files are packaged locally; no runtime third-party requests.

## Desk Lamp Arm 01

Source: https://polyhaven.com/a/desk_lamp_arm_01
Modeling/texturing: Kuutti Siitonen. Rigging: Yann Kervran.
License: CC0 1.0, https://polyhaven.com/license

The official 1K glTF, binary buffer and JPEG maps were combined into `desk-lamp.glb` without changing geometry or image data. Runtime placement rotates Y-up into Z-up, scales the prop for the stylized set and reduces normal-map strength. This is the source model's static pose, not an interactive lamp rig.

## Workbench, Bench Vise, Vernier Caliper

Creator: Grab3D. Cozy Tools & Workshop Kit.
Sources:
- https://grab3d.com/models/tools/workbench/
- https://grab3d.com/models/tools/bench-vise/
- https://grab3d.com/models/tools/vernier-caliper/

Original GLBs are unmodified. Runtime orientation, scale, environment lighting and normal-map strength are adjusted to fit the set. Grab3D discloses that these assets were created with procedural Blender scripts written with AI coding assistance; they are not scans. See `Grab3D-LICENSE.txt` for the original disclosure and CC0 dedication, verified for all three files.

`CC0-1.0.txt` contains the license text. `manifest.json` records shipped byte lengths and SHA-256 hashes. The room shell, mat artwork and remaining props are authored by this project. Furniture proportions are art direction, not physical scale evidence for the inspected object.
