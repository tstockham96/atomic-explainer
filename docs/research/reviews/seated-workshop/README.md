# Seated, stylized workshop sample

Responds to the rejection of the overhead realistic desk: centered seated eye line, fixed scenery, rounded colorful props, matte worktop, clear central mat. The original object orbit becomes an object turn; camera travel is a dolly along one fixed ray. Small components receive close-up framing, followed by a smooth return to the assembled object. The desk and props are shared across the Murph and imported-object viewers.

Reference direction: https://bruno-simon.com/ (playful rendered-world style, not copied geometry/code). All props and canvas graphics here are authored in the repository. The researched object retains its own geometry and surface materials. No new external assets or libraries are needed.

Validation: typecheck passes; 12 targeted unit tests pass; all 10 presentation and assembly-story browser tests pass in Chrome. Tests cover camera direction, unchanged component-local poses, static desk transform, optical transmission, reverse scrolling, reassembly, settings changes, responsive controls and a second-object integration fixture. Screenshots were inspected at desktop/mobile sizes. The second object screenshot is deliberately a construction fixture, not a fidelity claim.

Limitations: this remains an art-direction sample requiring user review, not parity with Bruno Simon’s full game. Props are static, not interactive physics objects. Approximate scales for uncalibrated imports carry no millimeter labels. Soft glass reflections vary with inspection angle; automated opacity checks alone do not establish visual quality.
